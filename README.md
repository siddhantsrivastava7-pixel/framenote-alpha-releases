# FrameNote Closed Alpha: releases

This repository only hosts **signed macOS builds** of the FrameNote Closed Alpha and the feed that installed copies use for automatic updates. It contains no source code.

## Install (once)
1. Download the latest `FrameNote-…-arm64.dmg` from **Releases** (Apple Silicon Macs).
2. Open it and drag **FrameNote** into **Applications**.
3. Open FrameNote and allow Screen Recording and Microphone access when asked.

## Updates
Installed copies check for new alpha versions automatically. Updates download in the background. **Restart & Update** appears when it is safe (never during a recording or while processing). Updates replace only the app: recordings, notes, settings and downloaded speech models stay as they are.

FrameNote processes recordings locally. Automatic transcripts may contain recognition errors; uncertain passages are highlighted for review.
